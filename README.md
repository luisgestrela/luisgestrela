### 🚀 Featured Projects

#### 📊 Startup Evaluation Platform — [Projeto-Catapimbas](https://github.com/luisgestrela/Projeto-Catapimbas)

Multi-institutional web platform for managing and evaluating startups and academic projects. Institutions organize evaluation panels, reviewers score projects with weighted rubrics, and the system computes the ranking, shows an animated podium, and exports results to `.xlsx`.

- 🔐 Role-based access (admin, coordinator, advisor, student, reviewer), HttpOnly cookie sessions, and per-institution data isolation on every query
- 🧮 Weighted ranking with tie-breaking, duplicate-evaluation protection at the database, API, and UI levels, plus audit logs
- 🔗 Single-use evaluation links with expiring hashed tokens, and QR codes for quick project access

#### 🎓 WitHub — [Withub](https://github.com/luisgestrela/Withub)

Functional React prototype of a STEAM academic portfolio platform. Students publish projects with versioning and privacy levels, while mentors follow each project through stages (review, mentoring, adjustments, approval, publication) and are the only ones who can publish it to the public feed.

- 🖼️ Public showcase with filters by STEAM area, technology, and institution, plus project pages with a digital certificate
- 👩‍🏫 Mentor portal with evaluation flow, private guidance, agenda, mentor network, and chat
- 🛡️ Route guards and a simulated API enforcing permissions per role
